# pack-firewalkerz-image-generator

A POC app to serve players in a Werewolf: The Apocalypse campaign; keeps descriptions and reference images of players and common NPCs on hand in app so that specific scenes and interactions can be rendered at will.

## Development Runtime

Use Node.js 24 for local development and deployment. With `nvm`, run `nvm use` from the project root, then install dependencies with `npm ci`.
